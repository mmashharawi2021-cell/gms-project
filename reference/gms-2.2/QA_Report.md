# تقرير التنفيذ والاختبارات — GMS 2.2

**التاريخ:** 14 نوفمبر 2026

**المراجع:** `GMS_SRS_v2_1_AR.docx` و`GMS_schema_v2_1_DRAFT.sql` ومراجعتا Claude وGemini اللتان قدمهما المستخدم.

## المراحل المنفذة

| المرحلة | ما أنجز | حالة التحقق |
|---|---|---|
| 1. حماية قاعدة البيانات | إزالة typmod ذي التقريب الصامت، قيود scale وFK منطقية، منع تعديل الخام والمعتمد والنهائي، مصدر ledger، قفل سعر الدورة وإغلاقها، تخصيص قراءة لكشف نهائي واحد | كود مكتوب وفحوص ساكنة؛ PostgreSQL لم يُشغَّل |
| 2. محرك الحسابات | دوال اعتماد زيارة، ترحيل تلقائي مشتق من دفتر مبالغ دقيقة، إغلاق الدورة، المدفوعات، إلغاء الدفعات بقيد عكسي، التسويات، الأرصدة الافتتاحية، مفاتيح عدم تكرار | اختبارات Decimal مرجعية ناجحة؛ PostgreSQL لم يُشغَّل |
| 3. SRS والتتبع | وثيقة 2.2 عربية تشمل التصحيحات وتفاصيل مالية وسجل الأسئلة Q01–Q24 ومصفوفة BR/FR/AT ومراحل التسليم | وثيقة Word تم إنشاؤها وعرض 27 صفحة بصريًا؛ PDF مشتق منها |
| 4. الاختبارات | سيناريو PG شامل لحالات القراءة غير الدقيقة، المساس بالسجلات، التفويض، الكسر، الدفعات، الدورات، السعر، الأرصدة؛ اختبارات Python لمرجع Decimal والتحقق الساكن | **12/12 اختبار محلي نجح**؛ اختبار PostgreSQL **لم ينفذ** |

## نتيجة الأوامر المنفذة فعلًا

```text
python -m unittest discover -s tests -p 'test_*.py' -v
Ran 12 tests
OK

bash tests/run_postgres.sh
PostgreSQL client psql not installed. Integration tests NOT RUN.
exit code: 3
```

هذه النتيجة لا تثبت سلامة SQL في PostgreSQL من ناحية الصياغة أو جميع قيود المعاملات، لأن PostgreSQL لم يكن متاحًا محليًا. يجب تشغيل سكربت الاختبار في PostgreSQL 16+ معزول وتسجيل النتيجة قبل أي اعتماد.

## الفجوات الحرجة قبل الإنتاج

1. **اختبارات PG الحقيقية:** لم يتم التأكد بعد من تنفيذ SQL أو صحة جميع Triggers/Functions داخل PostgreSQL 16/17.
2. **مصادقة التطبيق:** نظام الأدوار في SQL يفترض سياق `gms.actor_id` صادرًا من API موثوق. لا تكفي GUC لمنع انتحال المدير إذا أُعطي العميل اتصال SQL مباشرًا.
3. **المسارات الاستثنائية:** القراءة المصححة في سلسلة قد حوسبت دورة تالية؛ استبدال العداد في وسط الأسبوع؛ إثبات عدم فقد الصور؛ اختيار زمن القراءة مع ساعة هاتف غير موثوقة؛ هذه تحتاج دوال ومعالجة مدققة واختبارات إضافية.
4. **إغلاق الدورة:** وجود زيارات غير مجدولة أو معلقة يجب أن يدخل في تحقق الإغلاق في التطبيق قبل اعتماد الحساب. تحقق الدالة الحالي يعتمد أساسًا على المهام المرتبطة.
5. **أرصدة العميل:** قيمة الديون الافتتاحية غير معروفة لأن ملف Excel لم يفحص بعد. عدم اختراع بيانات حقيقية مطلوب.
6. **التخزين والنسخ:** لا توجد خدمة Object Storage مثبتة ولا نسخ يومية حقيقية أو اختبار Restore من قاعدة تشغيلية.
7. **واجهات مستخدم:** لم تبنَ تطبيقات Android وWeb في هذه المهمة. هذه حزمة مواصفات/SQL/اختبارات، لا المنتج النهائي.

## الخلاصة التنفيذية

**تم إنتاج الأصول المطلوبة للمراحل الأربع، لكن المرحلة الرابعة مكتملة محليًا في فحوص المنطق فقط وليست مكتملة اختبارًا تكامليًا.** لا يُنشر SQL 2.2 ولا يوقّع كمنصة مالية إنتاجية حتى إكمال اختبار PostgreSQL والتدقيق الأمني وتشغيل التطبيقات والتحقق من بيانات العميل.
