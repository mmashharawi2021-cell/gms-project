## 3. اختبار تطبيق Android على محاكي (تشغيل فعلي)

المحاكي: Android 37 (AVD مؤقت أُنشئ ثم حُذف)، الخادم: API مؤقت على قاعدة جديدة بيانات اصطناعية (DEV-*). التشغيل آليًا عبر adb/uiautomator.

| الخطوة | النتيجة |
|---|---|
| تثبيت APK وفتحه | واجهة عربية RTL |
| دخول أول (عنوان الخادم + مستخدم + كلمة مؤقتة + رمز تفعيل) | نجح؛ الخادم سجّل الجهاز |
| تغيير كلمة المرور المؤقتة | إلزامي ونجح |
| PIN 1234 | رُفض «رمز سهل التخمين»؛ 2580 قُبل |
| تنزيل المهام | مهمتان للمنطقة المخوّلة |
| إعادة تثبيت/تشغيل ← شاشة القفل | PIN خاطئ رُفض، الصحيح فتح التطبيق |
| إيقاف Wi-Fi والبيانات، إدخال 101.987 | «مسموح بمنزلتين عشريتين فقط — لن يتم التقريب» |
| إدخال 101.43 | عرض الاستهلاك 1.43 بدقة |
| الحفظ دون صورة | مرفوض «الصورة الأساسية إلزامية» |
| تصوير بكاميرا المحاكي ثم الحفظ Offline | 1 زيارة + 1 صورة بانتظار الإرسال؛ الخادم لم يستقبل شيئًا |
| قتل التطبيق (force-stop) وإعادة الفتح Offline | البيانات باقية (1/1)؛ تسجيل الخروج مرفوض لوجود بيانات غير مرسلة |
| تشغيل Wi-Fi | مزامنة تلقائية دون ضغط زر: زيارة + صورة |
| الخادم | 101.43 كما هي، وقت الهاتف «متسق» بدليل الساعة الرتيبة، صورة JPEG حقيقية 27 KB متحقق منها |
| اعتماد المدير | يظهر على الهاتف «اعتمدها المدير» |
| زيارة ثانية Offline ثم Wi-Fi (مزامنة أمامية + خلفية معًا) | وصلت مرة واحدة، الصورة المكررة قُوبلت بـ idempotency |
| إيقاف الجهاز من المدير ثم مزامنة | 403 ورسالة «أوقف المدير هذا الجهاز… البيانات غير المرسلة محفوظة» |

**أخطاء اكتشفها اختبار الجهاز وأُصلحت:** (1) مهمة الخلفية كانت تغلق اتصال قاعدة البيانات المشترك فتفشل مزامنة الواجهة (`database_closed`) ← اتصال مستقل للخلفية + busy_timeout؛ (2) قائمة المهام لم تتحدث بعد أول تنزيل ← تحديث بعد كل مزامنة؛ (3) عنوان خادم افتراضي مخفي كان يُرسل الدخول لخادم آخر على الجهاز ← حقل العنوان ظاهر وإلزامي.

## 5. نسخة الإصدار من التطبيق

`flutter build apk --release` نجح (66 MB). شُغّل على محاكي مؤقت: يبدأ دون أعطال (قاعدة SQLCipher وجدولة الخلفية تعمل بعد تقليص الكود)، ويرفض أي خادم لا يبدأ بـ https://. التوقيع حاليًا بمفتاح التطوير — يلزم مفتاح المشروع (`android/key.properties`) قبل التوزيع.

## 6. مشكلات وقيود متبقية (بصراحة)

1. **قرارات تحتاج العميل** (`docs/assumptions-and-decisions.md`): المنطقة الزمنية، حدود الثقة بالساعة، سياسة الاستبدال، أعمدة Excel الحقيقية، صيغة الإيصال، الاستضافة ومدة الاحتفاظ بالنسخ.
2. **ملف Excel الحقيقي وأرصدة العملاء الافتتاحية** غير متوفرة؛ لم تُخترع بيانات.
3. **المشرف الفائق لقاعدة البيانات** يستطيع تعطيل الحمايات (حد معروف في SRS §18.2) — يلزم فصل الصلاحيات في الإنتاج.
4. **معدل محاولات الدخول** في ذاكرة العملية (مع عاملين في الحاوية الحد لكل عامل)؛ القفل بعد 5 محاولات في القاعدة هو الحماية الأساسية. خلف عدة خوادم يلزم مخزن مشترك.
5. **تخزين الصور**: صورة MinIO الرسمية لم تعد متاحة على Docker Hub؛ استُبدلت بـ SeaweedFS (S3). اختيار مزوّد الإنتاج قرار صاحب المشروع.
6. **المزامنة في الخلفية** على Android يمكن أن يؤخرها النظام؛ المزامنة الأمامية وزر «مزامنة الآن» متاحان، والتطبيق يعرض عدد غير المؤكد.
7. **لا يمكن مسح بيانات هاتف مفقود عن بُعد** أثناء انقطاعه (كما في SRS)؛ البيانات مشفرة والجهاز يُرفض فور الاتصال.
8. **توقيع الإصدار**: APK الإصدار يحتاج مفتاح توقيع (`android/key.properties`) يملكه صاحب المشروع؛ دون ذلك يُوقّع بمفتاح التطوير ولا يصلح للتوزيع.
9. **طباعة جميع الكشوف دفعة واحدة**: صارت متوازية على أنوية المعالج (2,000 صفحة: 56 ث ← 24 ث). 5,000 صفحة ما زالت تقارب الدقيقة؛ الطباعة حسب المنطقة هي الأنسب يوميًا.
10. **المستودع ليس Git** ولم يُنشأ أي commit أو push.
11. **CI** مكتوب في `.github/workflows/ci.yml` ولم يُشغَّل لأن المشروع غير مرفوع إلى أي مستودع.
