# GMS — نظام إدارة مولدات الكهرباء وقراءات العدادات

| المسار | المحتوى |
|---|---|
| `db/sql/` | قاعدة البيانات (PostgreSQL 16، schema `gms`): الجداول، الحمايات، المحرك المالي، التشغيل، المزامنة/المراجعة، الصلاحيات |
| `services/api/` | FastAPI: المصادقة، الصلاحيات، الإدارة، المراجعة، المالية، مزامنة الهاتف والصور، التقارير PDF/Excel، استيراد Excel، النسخ والاستعادة. ترحيلات Alembic. |
| `apps/admin-web/` | لوحة المدير (Next.js، عربية RTL) عبر BFF بجلسات httpOnly |
| `apps/field-mobile/` | تطبيق الموظف (Flutter Android) Offline-First، تخزين مشفر، PIN/بصمة، مزامنة Wi-Fi فقط |
| `infra/` | Docker Compose (PostgreSQL، تخزين S3، API، Web، النسخ اليومي) و`.env.example` |
| `docs/` | التدقيق P0، سجل التقدم، مصفوفة التتبع، القرارات، دليل النشر، أدلة المدير والموظف، تقرير القبول والمشكلات |
| `reference/gms-2.2/` | الحزمة المرجعية الأصلية (SRS 2.2 وSQL المسودة) — للمرجعية فقط، **ليست** ترحيلات |

البدء: `docs/deployment-guide.md`. الحالة واختبارات القبول: `docs/progress.md` و`docs/acceptance-report.md`.

لا تُشغَّل الترحيلات أو أدوات الاختبار على قاعدة بيانات إنتاجية. لا بيانات حقيقية في المستودع؛ بيانات الاختبار اصطناعية (QA-*/E2E-*/DEV-*).
